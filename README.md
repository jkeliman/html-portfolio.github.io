# html-portfolio

Personal portfolio of John Kelimana, IT leader and web developer in Majuro, Marshall Islands.

Static HTML and CSS. No build step.

- `index.html` is the home page.
- `public/` holds the About, Contact and project pages.
- `styles.css` is the shared stylesheet.
- `assets/images/` holds project previews.

Preview locally:

```bash
python3 -m http.server 8000
```

The site began as a project from "The Complete 2023 Web Development Bootcamp" on Udemy.
