# html-portfolio

Personal portfolio of John Kelimana, IT leader and web developer in Majuro, Marshall Islands.

Static HTML and CSS. No build step.

- `index.html` is the home page.
- `public/` holds the About, Contact and project pages.
- `styles.css` is the shared stylesheet.
- `assets/images/` holds project previews.

Preview locally:

```bash
python3 -m http.server 8000
```

The projects are from [The Complete Full-Stack Web Development Bootcamp](https://www.udemy.com/course/the-complete-web-development-bootcamp/) on Udemy, created by [Dr. Angela Yu](https://www.udemy.com/user/4b4368a3-b5c8-4529-aa65-2056ec31f37e/).
